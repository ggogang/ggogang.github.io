개인용 채널 관리 도구

완성한 이야기를,
내 채널에.

직접 관리하는 YouTube 채널에 자체 제작 영상을 업로드하고 제목, 설명, 썸네일과 공개 상태를 관리하는 도구입니다.

어떤 도구인가요?

운영자가 자신의 Windows PC에서 실행하는 프로그램입니다. 가족·인생 사연 본편과 연결 쇼츠의 완성 파일을 선택한 채널에 전송합니다. 이 사이트는 프로그램과 데이터 처리 방식을 안내하며, 사이트 방문만으로 Google 계정에 연결하거나 영상을 업로드하지 않습니다.

01

내 채널 확인

운영자가 Google 인증 화면에서 권한을 승인합니다. 프로그램은 인증된 채널과 업로드할 채널이 같은지 확인합니다.

02

완성 파일 전송

준비한 영상, 썸네일, 제목과 설명을 YouTube API로 전송합니다. 전송 기록을 보관해 중복 업로드를 방지하고 중단된 전송을 이어갑니다.

03

공개 상태 관리

영상은 비공개로 전송한 뒤 처리 상태를 확인합니다. 운영자가 지정한 공개 작업은 YouTube 계정 및 API 프로젝트에 허용된 범위에서 실행합니다.

사용자와 데이터

이 도구는 운영자 본인이 관리하는 채널을 위한 개인용 도구입니다. 일반 방문자의 회원가입을 받지 않습니다. 채널 관리에 사용하는 Google 데이터와 인증정보를 광고, 판매 또는 AI 모델 학습에 사용하지 않습니다.
