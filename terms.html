목적과 이용 대상

꼬강 사연 업로드 도구는 운영자가 직접 관리 권한을 가진 YouTube 채널에 자체 제작 콘텐츠를 업로드하기 위한 개인용 프로그램입니다. 불특정 다수에게 계정 관리 서비스를 제공하거나 이용료를 받지 않습니다.

사용자의 선택

사용자는 권한을 가진 채널과 게시할 파일을 선택하고 제목·설명·썸네일·대상 시청자·합성 콘텐츠 표시·공개 여부를 확인해야 합니다. 프로그램의 업로드와 공개 명령은 별도로 실행됩니다. 계정 인증만으로 영상이 업로드되거나 공개되지 않습니다.

YouTube 이용 조건

이 도구는 YouTube API 서비스를 이용합니다. 이용자는 YouTube 서비스 약관을 준수해야 합니다. 콘텐츠 게시 권리와 정책 준수 책임은 게시자에게 있습니다. API 프로젝트 심사, 채널 기능 제한, 처리 지연 또는 서비스 변경에 따라 작업이 제한될 수 있으며 이 사이트는 Google 또는 YouTube의 승인이나 보증을 나타내지 않습니다.
